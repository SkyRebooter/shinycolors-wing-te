# ShinyColors WING TE 助手

用于《偶像大师 闪耀色彩》网页版的 Tampermonkey 浏览器脚本，协助完成 WING 单轮培育。

**当前版本 v0.6.8：112 项离线测试通过，当前版本尚未完成实机验证。** 历史 v0.5.3 仅验证过普通试镜结果对话及跨季接续，不能据此宣称当前版本可稳定全自动通关 TE。

## 安装

- [直接安装 userscript](https://raw.githubusercontent.com/SkyRebooter/shinycolors-wing-te/main/ShinyColorsWing.user.js)
- [下载篡改猴导入包](dist/WING_TE_Tampermonkey_v0.6.8.zip)
- [下载完整发布包](dist/WING_TE_full_v0.6.8.zip)

安装 Tampermonkey 后打开直接安装链接；也可在篡改猴管理面板 → 实用工具 → 导入 ZIP。更新后刷新游戏，面板标题应显示 `WING TE 助手 0.6.8`。

适用页面：[ShinyColors](https://shinycolors.enza.fun/)。先在游戏内选择偶像、支援、培育模式与道具，再启动面板。建议先运行 1 周，核对日志后再开启持续运行。需要时导出诊断以排查问题，分享诊断前请自行检查其中的账号与培育信息。

## 功能

- 工作、课程、试镜、季度结算与剧情推进；中文／日文界面适配。
- 工作事故率大于 10% 时休息。课程根据支援、强化与流行判定是否替代 Talk；当前策略不主动安排广播。
- S2 末周检查 Talk 预计粉丝是否足够晋级；S3 四万／五万、S4 十万粉丝路线。
- 技能优先攻击主动 → 增益 → 上限，展开必要前置并只规划倍率最高的四个攻击；支援卡 2.5 倍攻击排除。
- 半决赛／决赛通过客户端 AUTO 执行，装载流行1与收尾选择策略，并启用3倍速。AUTO 必须已解锁，最后一击不能保证。
- 记者采访自动拒绝，约定拒绝；对话选项侧重心情与思い出。
- 到达 Ending 结束时显示“培育完成”，停止当前运行，绝不自动重开下一轮。

## 保护与限制

只操作 WING；不自动购买或付费续关。提交前记录 pending，核验周推进；未知页面或错误弹窗停止。操作间隔至少400ms；标签页隐藏时暂停，超过10分钟停止。单次运行限1小时、600次操作。

技能和 UI 适配依赖客户端内部界面结构，客户端更新可能使脚本失效。倍率缺少“倍”字样时只能按其他字段排序；技能前置由网格推断；奖励、胜负和最后一击由游戏服务器裁定。

## 本地验证与打包

无 npm 第三方依赖。需要 Node.js 22+，打包需要 Python 3。

```sh
npm run check
npm test
npm run build
```

GitHub Actions 会执行同样的检查、测试与打包。构建脚本只使用 Python 标准库，并逐字节核对 ZIP 内的 userscript。
